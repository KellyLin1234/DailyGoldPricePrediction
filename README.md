# Gold Price Prediction Project

## Models Used
- Random Forest
- Gradient Boosting
- XGBoost
- LSTM
- Hybrid Model

## Results

| Model | MAE | RMSE | R² |
|------|-----|------|-----|
| RF | 836 | 1094 | 0.997 |
| GB | 948 | 1195 | 0.996 |
| XGB | 597 | 897 | 0.998 |
| LSTM | 6323 | 8608 | 0.817 |
| Hybrid | 2026 | 2318 | 0.966 |

## Conclusion
XGBoost performed the best among all models.
